# Week Number Widget — Website

This is the small marketing website for the Week Number Widget app. It's the page people land on to learn what the widget does, see screenshots, and download the app for their phone. The app itself (the actual phone widget) lives in a separate project.

## What it does
- Explains what the Week Number Widget is and why it's useful
- Shows off features and screenshots
- Points visitors to the download and to the project on GitHub

## Status
Working website. It's a simple, static web page (just text, styling, and a little interactivity — no login or database). Published at weeknumber.6x7.gr.

---
### For developers
Plain static site: `index.html`, `styles.css`, `script.js`, and `favicon.svg`. No build step or dependencies — open `index.html` in a browser to preview. `CNAME` sets the custom domain (`weeknumber.6x7.gr`) for GitHub Pages hosting. The companion app repo is at github.com/philipposk/WeekNumber-Widget.
