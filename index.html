Know which week it is

A small home-screen widget for iOS and Android. ISO 8601 week number, updates with the calendar, no ads or tracking.

Download GitHub
WEEK 47 2025

What you get

  • ISO 8601 weeks start on Monday, with an optional Sunday-start mode on iOS.
  • Home and lock screen on both platforms.
  • Light and dark follow system theme on Android; customizable on iOS.
  • Native code SwiftUI + WidgetKit on iOS, Kotlin on Android.
  • MIT licensed and free to use.
